# Thread Activity для BB

Отдельная панель **«Активность»** с общей лентой тредов по дням последней активности. Все машины, проекты и пользовательские секции объединены; самые свежие треды находятся сверху.

## Установка

Требуется BB **0.46.1 или новее** с Plugin SDK **0.6.49–0.6.x**. Первая проверенная версия — BB 0.46.1 / SDK 0.6.49.

```sh
bb plugin install https://github.com/artbear/bb-plugin-thread-activity
```

После установки откройте **«Активность»** на навигационной панели BB — значок истории. При узком окне откройте навигацию приложения. Штатный список тредов остаётся доступным.

В BB 0.47 с включённым плагином `sidebar-search` значок **«Активность тредов»** также появляется в заголовке списка тредов, непосредственно слева от кнопки поиска. Он открывает ту же панель. Для быстрого доступа используется DOM-маркер кнопки поиска; при изменении разметки BB или `sidebar-search` может потребоваться обновление плагина.

Обновление:

```sh
bb plugin update thread-activity
```

Установленная по URL версия отслеживает основную ветку репозитория. Обновление запускается штатной командой BB.

## Как устроена лента

- Группы **«Сегодня»**, **«Вчера»**, затем конкретные даты; дни определяются в часовом поясе клиента.
- Внутри дня — сортировка от последней активности к более ранней. При одинаковом времени порядок стабилизируется по ID.
- Каждый обычный тред показан отдельной строкой, включая дочерние треды.
- Закрепление, непрочитанность, запуск агента, проект, машина и секция не меняют порядок.
- В строке видны название, проект, машина, время, штатный индикатор статуса и отметка непрочитанного.
- Нажатие на название открывает тред. Обычные ссылки сохраняют возможность открытия в новой вкладке и копирования адреса.
- Лента получает обновления через общий кеш BB. Заголовки дат обновляются в полночь и при возвращении к приложению.
- Длинная лента виртуализирована: в DOM находятся только строки рядом с видимой областью.

Показываются **неархивные треды**. Архивные и внутренние скрытые треды исключены. Под «активными» здесь понимаются все неархивные чаты, включая те, где агент сейчас не работает.

### Что считается последней активностью

Используется публичное поле SDK **`latestAttentionAt`** — время значимой активности треда, которое BB использует для определения непрочитанных обновлений. Это семантика BB, а не самостоятельно вычисленное время последнего сообщения. Например, завершение хода агента может обновить это поле.

Поле `updatedAt` не используется: оно также может меняться при технических изменениях карточки. Открытие, закрепление и перенос между секциями сами по себе не дают треду приоритета в этой ленте. Во время выполняющегося хода положение меняется, когда BB обновляет `latestAttentionAt`; плагин не анализирует поток токенов.

## Данные и совместимость

Плагин читает треды, доступные текущему пользователю BB, через публичный SDK. Собственной базы, фонового опроса, внешних сервисов и дополнительных токенов нет. Данные чатов не отправляются в GitHub или другие сервисы.

Используются экспериментальные API BB. При изменении их контракта может потребоваться новая версия плагина. Копии внутреннего кода `thread-list` нет.

## Разработка

Нужны Node.js 22+ и npm. Версии BB CLI и SDK зафиксированы в зависимостях проекта.

```sh
git clone https://github.com/artbear/bb-plugin-thread-activity.git
cd bb-plugin-thread-activity
npm ci --ignore-scripts
npm run typecheck
npm test
npm run build
bb plugin install .
```

Сборка `dist/` не хранится в Git: BB собирает плагин при установке из репозитория. Runtime-зависимость виртуализации объявлена в `dependencies`, поэтому установка без dev-зависимостей поддерживается.

После изменения кода:

```sh
npm run build
bb plugin reload thread-activity
```
