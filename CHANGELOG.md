# История изменений

## 0.1.4

- «непрочитанные треды-родители» и «все родители» оставляют треды, которые не являются сабтредами. Вариант «все с дочерними» удалён. Значение по умолчанию — «непрочитанные треды-родители».

## 0.1.3

- В фильтре ленты первым добавлен вариант «все»: он показывает неархивные нескрытые треды без остальных условий. Значение по умолчанию по-прежнему «непрочитанные и без дочерних тредов».

## 0.1.2

- В ленте «Активность» один фильтр из четырёх вариантов. Пока сервер BB не перезапущен, выбранный вариант сохраняется между открытиями окна. После запуска сервера снова выбран «непрочитанные и без дочерних тредов».

## 0.1.1

- Добавлена кнопка открытия «Активности» слева от поиска в заголовке списка тредов BB 0.47 с плагином Sidebar Search.
- Кнопка восстанавливается после перерисовки заголовка и удаляется при отключении плагина.

## 0.1.0

- Добавлена отдельная панель «Активность» с общей лентой тредов по дням.
- Сортировка по `latestAttentionAt`, без приоритета закреплённых, непрочитанных или работающих тредов.
- Локальные календарные даты, обновление подписей в полночь и после возвращения к приложению.
- Виртуализация длинного списка, штатные ссылки и индикаторы состояния.
- Добавлены документация, автоматические проверки и CI.
